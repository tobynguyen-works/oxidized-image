## Introduction

Oxidized Image is a high-performance image optimization plugin for modern web frameworks, powered by [@napi-rs/image](https://image.napi.rs/).

<Callout>
	This plugin is powered by an image processing engine written in Rust. The process of rusting is
	oxidation — hence the name.
</Callout>
